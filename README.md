# 📚 Library Management System (Python OOP)

A simple **Library Management System** built using **Python Object-Oriented Programming (OOP)** concepts. This project allows users to add books, borrow books, return books, and manage a small library through a menu-driven console application.

---

## 🚀 Features

- 📖 Add Physical Books
- 💻 Add Digital Books
- 📚 Display All Books
- 🔄 Borrow Books
- ✅ Return Books
- 🎯 Menu-Driven Interface
- 🏗️ Object-Oriented Design

---

## 🛠️ OOP Concepts Used

- Classes & Objects
- Constructors (`__init__`)
- Encapsulation
- Inheritance
- Method Overriding (Polymorphism)
- Composition
